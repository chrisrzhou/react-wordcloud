02 / THE REACT COMPONENT

From data to delight.

The real library provides responsive SVG rendering using D3-cloud, customizable layout options, seeded randomness, tooltips and callbacks through a typed React API.

npm install @cecilialabs/d3-wordcloud-react
01 / DATA

Words with weight

Supply {text, value} objects. Numeric values determine word prominence.

02 / DESIGN

Layout control

Adjust scaling, font size, rotation and spiral in typed options.

03 / FEEDBACK

Interactions

Add tooltips, click/hover actions and colors via callbacks.

REACT / TYPESCRIPT
import { ReactWordCloud } from '@cecilialabs/d3-wordcloud-react';
import 'tippy.js/dist/tippy.css';
import 'tippy.js/animations/scale.css';

const words = [
  { text: 'research', value: 42 },
  { text: 'design', value: 28 },
  { text: 'open source', value: 18 },
];

export function ResearchCloud() {
  return <ReactWordCloud words={words} />;
}
